# 悟空-钉钉-Obsidian 三端打通 - 快速使用指南

## 📋 概述

本系统实现了悟空工作空间、钉钉文档和 Obsidian 三个平台的内容双向同步，确保您的工作记录在任何地方都能保持一致。

---

## 🚀 快速开始

### 1. 首次配置

#### 选项A：Git 同步（推荐）

```bash
# 在悟空工作空间初始化 Git
cd /home/wuying/.kinto-agent/workspace/projects/工作总结
git init
git remote add origin <your-git-repo-url>
git add .
git commit -m "Initial sync setup"
git push -u origin main

# 在本地 Obsidian vault 克隆仓库
cd /path/to/your/obsidian/vault
git clone <your-git-repo-url> .
```

#### 选项B：网盘同步

1. 安装网盘客户端（OneDrive/坚果云/Dropbox）
2. 将 `sync_for_obsidian/` 目录设置为同步文件夹
3. 在 Obsidian 中打开该文件夹作为 Vault

#### 选项C：手动复制

每次运行同步脚本后，手动将 `sync_for_obsidian/` 中的文件复制到 Obsidian vault

## 🔄 日常使用

### 场景1：悟空生成新日志后同步到钉钉

**自动方式**（推荐）：
等待定时任务执行（每天20:00自动同步）

**手动方式**：
```bash
cd /home/wuying/.kinto-agent/workspace/projects/工作总结
python sync_all.py
```

**预览模式**（不实际执行）：
```bash
python sync_all.py --dry-run
```

**详细输出**：
```bash
python sync_all.py --verbose
```

### 场景2：在钉钉编辑文档后同步回悟空

钉钉文档更新后，运行：
```bash
python sync_all.py
```

脚本会自动检测钉钉文档的最新版本并拉取到本地。

### 场景3：同步到 Obsidian

运行同步脚本后，根据您选择的同步方式：

**Git 方式**：
```bash
cd /path/to/your/obsidian/vault
git pull origin main
```

**网盘方式**：
等待网盘客户端自动同步（通常几分钟内完成）

**手动方式**：
复制 `sync_for_obsidian/` 中的文件到 Obsidian vault 对应目录

## ⚙️ 配置定时任务

### 创建每日同步任务

```bash
cron_use action=add \
  --name "三端同步-每日工作日志" \
  --schedule "0 20 * * *" \
  --payload.prompt "执行 /home/wuying/.kinto-agent/workspace/projects/工作总结/sync_all.py 脚本，完成悟空-钉钉-Obsidian三端同步"
```

### 查看已创建的定时任务

```bash
cron_use action=list
```

### 删除定时任务

```bash
cron_use action=remove --task-id <task-id>
```

## 🛠️ 故障排查

### 问题1：同步失败，提示 "unknown flag"

**原因**：dws 命令参数可能已更新

**解决**：
```bash
dws doc update --help
```
查看最新参数，然后修改 `sync_all.py` 中的命令。

### 问题2：钉钉文档搜索不到

**原因**：文档标题格式不匹配

**解决**：
- 确认钉钉文档标题格式为 "YYYY-MM-DD 工作日志"
- 检查是否有权限访问该文档
- 尝试手动搜索：`dws doc search --query "2026-07-04 工作日志"`

### 问题3：Obsidian 未收到更新

**Git 方式**：
```bash
cd /path/to/your/obsidian/vault
git status  # 检查是否有未提交的更改
git pull origin main  # 重新拉取
```

**网盘方式**：
- 检查网盘客户端是否正常运行
- 查看同步日志，确认是否有错误

**手动方式**：
- 确认复制的文件路径正确
- 检查文件权限

### 问题4：索引文件损坏

**解决**：
```bash
# 备份当前索引
cp sync_index.json sync_index.json.bak

# 重新生成索引
python sync_all.py
```

## 📊 同步规则说明

### 冲突解决策略

当前配置为 `newest_wins`（最新版本获胜）：
- 比较三端的最后修改时间
- 选择最新的版本作为基准
- 其他版本的更改需要手动合并

### 同步频率建议

- **工作日志**：每天至少同步一次（建议20:00）
- **周总结**：每周五下班前同步
- **月报**：每月最后一天同步

## 💡 最佳实践

### 1. 单一编辑源原则

尽量只在一个平台编辑内容，其他平台作为只读副本：
- **推荐编辑平台**：钉钉文档（支持多人协作）
- **只读平台**：悟空工作空间、Obsidian

### 2. 定期备份

每周备份一次 `sync_index.json` 和重要文档：
```bash
tar -czf backup_$(date +%Y%m%d).tar.gz work_logs/ weekly_summaries/ sync_index.json
```

### 3. 使用标签分类

在 Obsidian 中使用标签管理文档：
```markdown
#daily-note #work-log #2026-07
```

### 4. 建立模板库

将常用的日志格式保存为模板：
```
templates/
├── daily_log_template.md
├── weekly_summary_template.md
└── monthly_report_template.md
```

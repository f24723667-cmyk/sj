# 团队周报汇总系统 v2.0

## 📖 概述

本skill提供一套**完整的团队周报自动化汇总方案**，通过整合钉钉OA日志系统和AI表格两种数据源，自动抓取团队成员的周报内容，进行智能分析和归纳，生成结构化的团队周报报告。

### ✨ 核心特性

- ✅ **双数据源整合** - 同时支持钉钉OA日志和AI表格，确保数据完整性
- ✅ **智能分析** - 自动识别共同问题、重点项目、关键成果
- ✅ **灵活配置** - 可自定义团队成员列表、时间范围、汇总维度
- ✅ **一键生成** - 自动生成Markdown格式的团队周报，可直接发送或保存为文档
- ✅ **权限友好** - 基于钉钉官方API，尊重权限控制，不越权访问
- ✅ **业务表格深度集成** - 特别支持"设计需求提交表"等业务AI表格的结构化数据分析（完成率、平均时长、工作量分布）

### 🎯 适用场景

- 团队管理者需要每周汇总团队成员的工作进展
- 项目经理需要跟踪多个项目的整体进度
- 部门负责人需要向上一级汇报团队整体工作情况
- 需要对比团队成员工作负荷和产出效率
- **设计团队**需要统计设计需求完成情况、平均完成时长、待处理需求等关键指标

## 🚀 快速开始

### 前置要求

1. **钉钉账号** - 已登录钉钉客户端，具备管理员或团队负责人权限
2. **悟空权限** - 具备使用 `dws report`、`dws aitable`、`dws doc`、`dws contact` 工具的权限
3. **团队成员配置** - 需要准备团队成员的姓名或userId列表
4. **数据源准备**（至少一种）：
   - **OA日志**：团队成员已将您设为日志接收人
   - **AI表格**：已创建团队周报AI表格，成员定期填写

### 第二步：选择数据源并配置

#### 方案A：仅使用OA日志（适合已有OA日志习惯的团队）

**前提**：团队成员提交日志时将您设为接收人

**配置步骤**：
1. 确认团队成员已将您添加为日志接收人
2. 测试能否查看他们的日志：
   ```bash
   dws report inbox list \
     --start "2026-07-01T00:00:00+08:00" \
     --end "2026-07-07T23:59:59+08:00" \
     --cursor 0 --size 20 --format json
   ```
3. 如果能看到成员的日志，说明配置成功

#### 方案B：仅使用AI表格（适合结构化数据收集）

**前提**：已创建团队周报AI表格

**配置步骤**：
1. 创建AI表格"团队周报"，设置字段：
   - 姓名（单选/文本）
   - 日期（日期）
   - 本周工作总结（多行文本）
   - 下周计划（多行文本）
   - 问题与建议（多行文本）
   - 重点项目进展（多行文本）
2. 获取 `baseId` 和 `tableId`
3. 测试读取数据：
   ```bash
   dws aitable record list \
     --base-id <baseId> \
     --table-id <tableId> \
     --format json
   ```

#### 方案C：双数据源整合（推荐⭐⭐⭐⭐⭐）

**前提**：同时具备OA日志和AI表格

**优势**：
- OA日志作为正式汇报渠道
- AI表格用于快速收集和结构化分析
- 两者互补，确保数据完整性

**配置步骤**：
1. 按方案A配置OA日志
2. 按方案B配置AI表格
3. 在汇总时优先使用AI表格（结构化好），缺失时用OA日志补充

## 🔄 数据源详细说明

### OA日志数据源

#### 如何确认团队成员已将您设为接收人？

1. 让团队成员在提交日志时，在"接收人"中选择您
2. 或者联系钉钉管理员，将您设置为团队的默认日志接收人

#### 如何获取团队成员的staffId？

```bash
# 方法1：通过通讯录查询
dws contact search --name "王梦薇" --format json

# 方法2：通过部门查询成员列表
dws contact department members --dept-id <部门ID> --format json
```

#### 常见问题

**Q：看不到某些成员的日志？**  
A：可能原因：
- 该成员未将您设为接收人
- 该成员本周未提交日志
- 权限不足（非同一部门或非直属下级）

**解决方案**：
- 联系该成员，请其在提交日志时将您添加为接收人
- 或改用AI表格方案

---

### AI表格数据源

#### 如何创建团队周报AI表格？

1. 打开钉钉，进入"AI表格"应用
2. 点击"新建表格"，选择"空白表格"
3. 设置以下字段：

| 字段名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| 姓名 | 单选/文本 | 是 | 从团队成员列表中选择 |
| 日期 | 日期 | 是 | 周报所属周的结束日期（如周五） |
| 本周工作总结 | 多行文本 | 是 | 列出本周完成的主要工作 |
| 下周计划 | 多行文本 | 否 | 下周工作计划 |
| 问题与建议 | 多行文本 | 否 | 遇到的问题和改进建议 |
| 重点项目进展 | 多行文本 | 否 | 参与的重点项目进展情况 |
| 工作时长 | 数字 | 否 | 本周工作小时数（可选） |
| 满意度评分 | 单选 | 否 | 1-5分自评（可选） |

4. 保存表格，获取 `baseId` 和 `tableId`
5. 分享表格给团队成员，设置编辑权限

#### 如何获取baseId和tableId？

```bash
# 列出您有权限的所有AI表格
dws aitable base list --format json

# 查看某个表格的详细信息（包含tableId）
dws aitable table list --base-id <baseId> --format json
```

#### 常见问题

**Q：成员忘记填写怎么办？**  
A：可以在周四下午发送提醒消息：
```bash
dws chat message send --group <团队群ID> --content "🔔 温馨提醒：请于明天（周五）18:00前填写本周周报，谢谢配合！\n\n填写链接：<AI表格链接>"
```

**Q：如何确保数据质量？**  
A：建议在AI表格中设置：
- 必填字段验证
- 字数下限（如"本周工作总结"至少50字）
- 示例模板（提供填写范例）

如果您的团队使用**"设计需求提交表"**作为工作数据源，本skill已内置对该表格的深度分析支持。

#### 表格信息
- **表格名称**: 设计需求提交表
- **baseId**: `QG53mjyd80RwNKL3TXlGA0yNV6zbX04v`

- **详细说明**: 参见 [references/design-request-table-guide.md](./references/design-request-table-guide.md)

#### 自动分析维度
当检测到该表格时，系统会自动生成以下分析：

1. **工作量统计** - 本周新增需求总数、按设计师分组的工作量分布

3. **待处理清单** - 未完成需求的详细列表及期望完成日期
4. **类型分布** - 门店广告/效果图/电子版等类型的占比分析
5. **重点项目识别** - 高负荷设计师、重点门店、高价值项目

#### 集成到周报的方式

在团队周报prompt中增加以下步骤：

```markdown

2. 筛选本周提交的记录（按"提交时间"字段过滤）
3. 按以下维度分析：
   - 总需求数、已完成数、进行中数
   - 按设计师分组的工作量统计
   - 平均完成时长（从"需求完成时长"字段计算）

4. 将分析结果整合到"团队工作概览"和"成员工作详情"章节
```

## 🛠️ 管理命令速查

### 查看团队成员的OA日志

```bash
# 查看某位成员本周的日志
dws report inbox list \
  --start "2026-07-01T00:00:00+08:00" \
  --end "2026-07-07T23:59:59+08:00" \
  --sender-user-ids "staffId1" \
  --cursor 0 --size 20 --format json

# 查看多位成员的日志
dws report inbox list \
  --start "2026-07-01T00:00:00+08:00" \
  --end "2026-07-07T23:59:59+08:00" \
  --sender-user-ids "staffId1,staffId2,staffId3" \
  --cursor 0 --size 50 --format json
```

### 读取AI表格数据

```bash
# 读取本周的所有记录
dws aitable record list \
  --base-id <baseId> \
  --table-id <tableId> \
  --filter '{"field": "日期", "operator": ">=", "value": "2026-07-01"}' \
  --format json
```

### 查看已生成的团队周报

```bash
# 列出所有团队周报文档
dws doc search --query "团队周报" --folder "团队周报" --format json

# 读取某份周报
dws doc read --node <nodeId> --format json
```

### 1. 权限问题
- OA日志只能查看已将您设为接收人的成员日志
- AI表格需要团队成员有编辑权限
- 如需查看全团队日志，请联系钉钉管理员设置权限

### 2. 数据完整性
- 如果有成员未提交周报，报告中会明确标注
- 建议在周报截止前1天发送提醒
- 可以设置AI表格的必填字段验证，减少漏填

### 3. 时间范围
- 周报统计周期通常为周一至周日或周一至周五
- 根据团队实际情况调整
- 建议在周五18:00生成，给成员留出填写时间

### 4. 数据隐私
- 团队周报仅供内部使用，不要外传
- 敏感信息（如薪资、绩效评分）不建议纳入汇总
- 尊重成员隐私，汇总时聚焦工作本身

### 5. 报告质量
- 自动生成的报告可能需要人工润色
- 共同问题分析要深入，避免表面化
- 管理建议要具体可执行，不要泛泛而谈

## 🔍 故障排查

### 问题1：看不到团队成员的OA日志

**可能原因**：
- 成员未将您设为接收人
- 成员本周未提交日志
- 权限不足

**解决方案**：
1. 联系成员，请其在提交日志时将您添加为接收人
2. 检查成员是否已提交：`dws report outbox list`（需要成员授权）
3. 改用AI表格方案

### 问题2：AI表格读取失败

**可能原因**：
- baseId或tableId错误
- 权限不足
- 表格被删除

**解决方案**：
1. 重新获取baseId和tableId：`dws aitable base list`
2. 确认您有表格的查看权限
3. 检查表格是否存在

### 问题3：汇总报告内容为空

**可能原因**：
- 时间范围设置错误
- 数据源未配置
- 成员未提交数据

**解决方案**：
1. 检查时间范围是否正确（本周的起止日期）
2. 确认至少配置了一种数据源
3. 检查成员是否已提交周报

### 问题4：共同问题分析不准确

**可能原因**：
- 数据量太少（<3人）
- 成员填写不规范
- 关键词提取算法局限

**解决方案**：
1. 增加样本量（至少3-5人）
2. 规范成员填写格式（提供模板）
3. 人工复核和补充分析

## 💡 常见问题 FAQ

### Q1：我可以只使用OA日志或只使用AI表格吗？
**A**：可以。Skill支持三种模式：
- 仅OA日志
- 仅AI表格
- 双数据源整合（推荐）

根据您的实际情况选择即可。

### Q2：如果团队成员没有将我看为OA日志接收人怎么办？
**A**：有两种解决方案：
1. 联系团队成员，请其在提交日志时将您添加为接收人
2. 改用AI表格方案，让成员直接填写表格

### Q3：我可以自定义周报的格式吗？
**A**：可以。修改任务prompt中的"第六步：生成团队周报"部分，调整章节结构和内容要求即可。

### Q4：这个系统会消耗很多算粒吗？
**A**：每周执行一次，消耗的算粒可控。主要消耗在：
- 读取OA日志（每条日志需要调用entry get）
- 读取AI表格记录
- 生成报告文本

建议设置在周五18:00执行，避开高峰时段。

### Q5：如何将生成的周报发送给上级领导？
**A**：有三种方式：
1. 保存到钉钉文档后，分享链接给领导
2. 导出为PDF或Word文档后发送
3. 直接复制Markdown内容粘贴到邮件或聊天中

### Q6：可以汇总多个团队的周报吗？
**A**：可以。只需：
1. 配置多个团队的成员列表
2. 在报告中按团队分组展示
3. 增加"跨团队协作"章节

### Q7：如何确保周报的质量？
**A**：建议：
1. 规范成员填写格式（提供模板和示例）
2. 设置AI表格的必填字段和字数下限
3. 人工复核自动生成的报告，必要时补充分析
4. 定期收集团队反馈，持续优化汇总逻辑
